Инструкция

Как пользоваться сайтом

Прочитай один раз, это займёт три минуты. Ты решаешь задания, а робот проверяет их и отвечает. Чтобы отправлять решения, нужен бесплатный аккаунт на GitHub.

Создай аккаунт на GitHub (один раз)

  • Открой github.com/signup.
  • Впиши почту, придумай пароль и ник (латиницей).
  • Подтверди почту кодом из письма. Это бесплатно.
Ник — не настоящая фамилия. Всё, что ты отправляешь, видно всем в интернете. Придумай псевдоним вроде snake_42 и скажи его учителю.

Выбери задание

На главной выбери урок и задание. Слева — условие и пример, справа — шпаргалка с теорией: она подскажет, что вспомнить.

Напиши код

Пиши прямо в окне на странице задания. Ничего устанавливать не нужно, код сохраняется в твоём браузере. Можно писать и в VS Code или Thonny, а потом вставить сюда.

Отправь на проверку

  • Впиши ник и нажми «Отправить на проверку».
  • Откроется GitHub с готовой заявкой. Войди в аккаунт, если попросит.
  • Нажми зелёную кнопку Submit new issue.

Прочитай ответ робота

Через минуту под заявкой появится комментарий: Решено или список того, что не так. Если есть ошибки: нажми ⋯ → Edit у своей заявки, исправь код и сохрани. Робот проверит ещё раз.

Дальше

Пройди тест и покажи свой проект другим. В разделе «Журнал» учитель видит, какие задания сданы.

Частые вопросы

Робот не ответил

Подожди 2–3 минуты и обнови страницу. Если ответа нет, проверь, что заявка создана (она видна во вкладке Issues) и что название начинается с «[Сдача]». Скажи учителю.

Можно без аккаунта?

Да. Скачай репозиторий (Code → Download ZIP), решай в VS Code и проверяй командой python check.py 2.4. Покажи учителю экран с [ OK ].

GitHub не открывается

Работай в варианте без аккаунта и покажи результат учителю. Тест можно пройти и офлайн: открой файл docs/quiz.html из скачанного архива.

Что нельзя отправлять

Пароли, телефон, адрес, настоящую фамилию и чужой код без разрешения. Только свои решения и проекты.
