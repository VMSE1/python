# Инструкция для учителя

Сайт: https://vmse1.github.io/python/ · Репозиторий: https://github.com/VMSE1/python
Первичный запуск сайта — в файле `ЗАПУСК_САЙТА.md`.

## Что видит ученик

1. При первом заходе поверх сайта открывается **окно-инструкция**: 5 шагов с анимацией (создать аккаунт → выбрать задание → написать и проверить → отправить → получить ответ). Можно пролистать, поставить на паузу или пропустить. Снова открыть — кнопка «Как это работает» в шапке.
2. **Карта курса**: кружки заданий по урокам. Серый — не начато, синий контур — проверено в браузере, зелёный — отправлено, жёлтый — следующее.
3. **Страница задания**: условие, пример «ввод → вывод», окно для кода, справа шпаргалка с теорией.
4. Кнопка **«Проверить здесь»** запускает тесты прямо в браузере (Python работает на самом сайте, интернет-библиотеки не нужны). Ответ за 1–3 секунды: ✅ или список того, что не так. Бесконечный цикл останавливается через 8 секунд.
5. Кнопка **«Отправить учителю»** открывает GitHub с готовой заявкой. Ученик нажимает *Submit new issue*. Робот проверяет код на сервере ещё раз и отвечает комментарием.

Первая загрузка проверки тянет около 13 МБ (Python), дальше всё из кэша браузера.

## Кабинет учителя (виден только тебе)

Страница `teacher.html` (в меню учеников ссылки на неё нет). Вход:

1. Открой https://github.com/settings/tokens/new?description=python-course-teacher&scopes= и создай токен **без единой галочки** (срок 90 дней). Скопируй токен `ghp_…`.
2. На сайте открой `.../teacher.html`, вставь токен, нажми «Войти». Сайт спросит у GitHub, чей это токен, и пустит, только если аккаунт `VMSE1` (владелец репозитория). Чужой аккаунт или неверный токен — отказ.
3. После входа в меню появляется пункт **«Кабинет»**.

В кабинете: **Сводка** (таблица «ученик × задание», кто застрял на 3+ попытках), **Заявки** (последние сдачи со ссылками), **Ученики** (сопоставление ник → фамилия, класс), **Тест** (вставляешь коды результатов), **Управление** (быстрые ссылки: Issues, Actions, настройки сайта, файлы для правки).

**Что важно понимать честно:**
- Сайт статический (GitHub Pages), у него нет своего сервера. Вход проверяет владельца через GitHub, но код страницы публичный. Поэтому в кабинете нет секретных данных: сдачи и так лежат в публичных Issues.
- Реальные фамилии ты вводишь в «Ученики», и они хранятся **только в твоём браузере** (не на GitHub и не на сайте). Сделай «Выгрузить файл», иначе при очистке браузера потеряются.
- Токен без прав ничего не может изменить, даже если его кто-то увидит. По умолчанию он хранится до закрытия вкладки; галочка «запомнить» сохраняет его на этом компьютере.
- Вход с токеном также поднимает лимит запросов к GitHub с 60 до 5000 в час.
- Не заходи в кабинет с общего школьного компьютера с галочкой «запомнить». Нажми «выйти».

Ученики видят друг друга в публичных Issues (по нику), если GitHub открыт.

## Как добавить задание (5 минут)

1. Скопируй папку `tools/template_task/` в `lessons/lessonN/task_M_название/`.
2. Заполни `task.json` (условие, пример, подсказка, заготовка `starter`, проверка `cases` или `funcs`). Подробности и формат — в `CONTRIBUTING.md`.
3. Положи рядом файл-заготовку (имя из поля `file`, содержимое как `starter`).
4. Проверь у себя: `python check.py 6.1 --file мой_эталон.py` должен показать `[ OK ]`.
5. Загрузи изменения на GitHub (Add file → Upload files или `git push`). Сайт, форма сдачи и README обновятся сами за 1–2 минуты.

Новый урок: создай папку `lessons/lesson6/` и файл `lesson.json` с текстом `{"title": "Название урока"}`.

## Как добавить плашку теории

Открой `docs/data/theory.js` (на GitHub: карандаш у файла). Добавь объект в `THEORY`:

```
{"id":"l6-new","l":6,"t":"Заголовок","x":"Короткий текст","c":"print(1)","k":""}
```

`l` — номер урока, `c` — пример кода (можно `null`), `k` — `"warn"` для жёлтой плашки «Осторожно».
Чтобы плашка показывалась справа в конкретном задании, добавь её `id` в `THEORY_MAP` (например `"6.1":["l6-new"]`). Если для задания ничего не указано, показываются все плашки его урока.

## Дизайн: как менять

- Цвета и шрифты — в начале `docs/site.css` (блок `:root`). Светлая и тёмная темы переключаются кнопкой в шапке.
- Страницы — `docs/*.html`. Картинок нет: иллюстрации нарисованы кодом (SVG), поэтому сайт быстрый и работает в РФ без внешних шрифтов и CDN.
- Для следующих правок дизайна я использовал открытый скилл **Impeccable** (github.com/pbakaus/impeccable, ~83 тыс. звёзд). Чтобы он был и у тебя в Claude Code: `/plugin marketplace add pbakaus/impeccable`, затем `/impeccable critique`, `/impeccable polish` и т. д. по странице.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Сайт не открывается | Settings → Pages → Source = GitHub Actions; Actions → «Сайт» → Run workflow |
| Робот не отвечает на сдачу | Actions → «Проверка сдачи» → открой последний запуск; пришли скриншот |
| Кабинет или Проекты пустые | лимит GitHub API (60 запросов в час с одного адреса) или нет сдач; открой Issues напрямую |
| GitHub не открывается в школе | ученики скачивают ZIP и проверяют `python check.py N`; тест открывается офлайн (`docs/quiz.html`) |

## Ограничения

- Ученикам нужен аккаунт GitHub (бесплатный).
- Проверка сравнивает вывод программы с ожидаемым. Ученик может получить ❌ за другое слово в выводе. Тесты читаются в `task.json` открыто.
- Решения заданий в репозитории нет. Они в отдельном архиве у тебя.
