# Задание 2.1. Светофор

Спроси цвет светофора. `красный` → `Стой`, `жёлтый` → `Жди`, `зелёный` → `Иди`, любой другой → `Нет такого цвета`.

**Пример.** Ввод:

```
красный
```

Вывод:

```
Стой
```

**Подсказка:** `if / elif / else`.

**Файл:** `svetofor.py`

**Проверка у себя:** `python check.py 2.1`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
