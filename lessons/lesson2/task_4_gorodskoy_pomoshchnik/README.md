# Задание 2.4. Городской помощник 1.0

Спроси расстояние в км. До 2 км включительно — `пешком`, до 8 км включительно — `на наземном транспорте`, иначе — `на метро`. Выведи `Рекомендую: <способ>`.

**Пример.** Ввод:

```
5
```

Вывод:

```
Рекомендую: на наземном транспорте
```

**Подсказка:** Три ветки: `if`, `elif`, `else`. Расстояние — `float`.

**Файл:** `gorodskoy_pomoshchnik.py`

**Проверка у себя:** `python check.py 2.4`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
