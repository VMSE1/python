# Задание 2.10. Время суток

Спроси час (0–23). 6–11 — `Утро`, 12–17 — `День`, 18–22 — `Вечер`, остальное — `Ночь`.

**Пример.** Ввод:

```
14
```

Вывод:

```
День
```

**Подсказка:** Цепочка `if / elif / else` с границами.
