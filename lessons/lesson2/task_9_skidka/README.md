# Задание 2.9. Скидка в магазине

Спроси сумму покупки. От 1000 ₽ скидка 5%, от 5000 ₽ — 10%, от 10000 ₽ — 15%. Выведи `К оплате: <сумма>` (без копеек, целое число).

**Пример.** Ввод:

```
6000
```

Вывод:

```
К оплате: 5400
```

**Подсказка:** Проверяй от большей суммы к меньшей.

**Файл:** `skidka.py`

**Проверка у себя:** `python check.py 2.9`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
