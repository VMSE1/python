# Задание 2.8. Чётное или нечётное

Спроси число. Выведи `Чётное` или `Нечётное`. Если число отрицательное, добавь к ответу ` (отрицательное)`. Нуль — `Чётное`.

**Пример.** Ввод:

```
-3
```

Вывод:

```
Нечётное (отрицательное)
```

**Подсказка:** Остаток от деления на 2: `n % 2`.

**Файл:** `chet.py`

**Проверка у себя:** `python check.py 2.8`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
