# Задание 2.6. Три стороны

Спроси три стороны (по одной в строке). Если треугольник существует (каждая сторона меньше суммы двух других) — выведи `Существует`, иначе `Не существует`.

**Пример.** Ввод:

```
3
4
5
```

Вывод:

```
Существует
```

**Подсказка:** Нужно проверить все три неравенства сразу.

**Файл:** `treugolnik.py`

**Проверка у себя:** `python check.py 2.6`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
