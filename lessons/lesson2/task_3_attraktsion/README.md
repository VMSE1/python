# Задание 2.3. Аттракцион

Спроси рост (см) и возраст. Можно, если рост не меньше 120 **и** возраст не меньше 7: выведи `Можно`, иначе `Нельзя`.

**Пример.** Ввод:

```
130
10
```

Вывод:

```
Можно
```

**Подсказка:** Условие с `and`.

**Файл:** `attraktsion.py`

**Проверка у себя:** `python check.py 2.3`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
