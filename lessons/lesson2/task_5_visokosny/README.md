# Задание 2.5. Високосный год

Спроси год. Если он високосный — выведи `Високосный`, иначе `Обычный`. Год високосный, если делится на 4, но не на 100, либо делится на 400.

**Пример.** Ввод:

```
2024
```

Вывод:

```
Високосный
```

**Подсказка:** Используй `%` и `and` / `or` в одном условии.

**Файл:** `visokosny.py`

**Проверка у себя:** `python check.py 2.5`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
