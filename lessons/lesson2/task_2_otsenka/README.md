# Задание 2.2. Оценка по баллам

Спроси баллы (0–100). От 85 — `Оценка: 5`, от 65 — `Оценка: 4`, от 45 — `Оценка: 3`, иначе `Оценка: 2`.

**Пример.** Ввод:

```
70
```

Вывод:

```
Оценка: 4
```

**Подсказка:** Проверяй от большего порога к меньшему.

**Файл:** `otsenka.py`

**Проверка у себя:** `python check.py 2.2`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
