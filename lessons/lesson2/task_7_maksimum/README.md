# Задание 2.7. Максимум из трёх

Спроси три числа (по одному в строке) и выведи самое большое. Функцию `max` не используй: только `if`.

**Пример.** Ввод:

```
4
9
2
```

Вывод:

```
9
```

**Подсказка:** Сравнивай по очереди и храни лучшее в переменной.

**Файл:** `maksimum.py`

**Проверка у себя:** `python check.py 2.7`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
