# Задание 5.3. Ввод числа с повтором

Спрашивай число, пока пользователь не введёт целое. На неправильный ввод пиши `Ошибка, попробуй ещё раз`. В конце выведи `Принято: <число>`.

**Пример.** Ввод:

```
abc
-3
```

Вывод:

```
Ошибка, попробуй ещё раз
Принято: -3
```

**Подсказка:** `while True`, внутри `try / except ValueError`, `break` при успехе.

**Файл:** `vvod_chisla.py`

**Проверка у себя:** `python check.py 5.3`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
