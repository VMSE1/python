# Задание 5.1. Безопасный int

Напиши функцию `safe_int(text)`: если строку можно превратить в целое — вернуть число, иначе вернуть `None`. Программа не должна падать.

**Пример вызова:**

```python
>>> safe_int("abc")
None
```

**Подсказка:** `try: return int(text)` и `except ValueError: return None`.

**Файл:** `safe_int.py`

**Проверка у себя:** `python check.py 5.1`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
