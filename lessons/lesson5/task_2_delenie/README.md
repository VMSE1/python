# Задание 5.2. Безопасное деление

Напиши функцию `safe_divide(a, b)`: вернуть `a / b`, а при делении на ноль — `None`. Используй `try / except ZeroDivisionError`.

**Пример вызова:**

```python
>>> safe_divide(1, 0)
None
```

**Подсказка:** Не проверяй `b == 0` — пусть Python выбросит ошибку, а ты её поймаешь.

**Проверка у себя:** `python check.py 5.2`
