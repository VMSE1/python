# Задание 5.4. Городской помощник 3.0

Собери проект. Спроси имя. Потом в цикле спрашивай расстояние (`стоп` — выход). Если ввели не число — `Это не число`, программа не падает. Иначе выведи `<имя>, рекомендую: <способ>` (до 2 км — `пешком`, до 8 — `на наземном транспорте`, иначе `на метро`). В конце — `Хорошей дороги!`.

**Пример.** Ввод:

```
Анна
abc
1.5
12
стоп
```

Вывод:

```
Это не число
Анна, рекомендую: пешком
Анна, рекомендую: на метро
Хорошей дороги!
```

**Подсказка:** Функция `recommend` из 3.4 + `try / except` из 5.3.

**Файл:** `gorodskoy_pomoshchnik_3.py`

**Проверка у себя:** `python check.py 5.4`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
