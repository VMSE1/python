# Задание 4.1. Сколько слов

Спроси фразу. Выведи `Слов: <число>`.

**Пример.** Ввод:

```
я учу python
```

Вывод:

```
Слов: 3
```

**Подсказка:** Метод строки `.split()` и `len()`.

**Файл:** `slova.py`

**Проверка у себя:** `python check.py 4.1`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
