# Задание 4.3. Счётчик букв

Напиши функцию `letter_count(text, letter)`: сколько раз буква встречается в тексте. Регистр не важен.

**Пример вызова:**

```python
>>> letter_count("Банан", "а")
2
```

**Подсказка:** `.lower()` для обеих строк и `.count()` либо цикл.

**Файл:** `chastota.py`

**Проверка у себя:** `python check.py 4.3`
