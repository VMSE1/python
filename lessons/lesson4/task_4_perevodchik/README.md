# Задание 4.4. Переводчик

Заведи словарь: `кошка` → `cat`, `собака` → `dog`, `дом` → `house`. Пользователь вводит слова, пока не введёт `стоп`. Для каждого слова выведи перевод, а если слова нет в словаре — `не знаю`.

**Пример.** Ввод:

```
кошка
рыба
стоп
```

Вывод:

```
cat
не знаю
```

**Подсказка:** Словарь `{...}`, проверка `word in d`, `d[word]`.

**Файл:** `perevodchik.py`

**Проверка у себя:** `python check.py 4.4`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
