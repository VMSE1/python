# Задание 4.5. Приветствие в файле

Спроси имя. Запиши в файл `hello.txt` строку `Привет, <имя>!`. Потом прочитай файл и выведи его содержимое на экран.

**Пример.** Ввод:

```
Анна
```

Вывод:

```
Привет, Анна!
```

**Подсказка:** `open("hello.txt", "w", encoding="utf-8")` и `with`.

**Файл:** `fayl.py`

**Проверка у себя:** `python check.py 4.5`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
