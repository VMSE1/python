# Задание 4.2. Палиндром

Напиши функцию `is_palindrome(s)`: `True`, если строка читается одинаково в обе стороны. Регистр и пробелы игнорируются.

**Пример вызова:**

```python
>>> is_palindrome("Шалаш")
True
```

**Подсказка:** Срез `s[::-1]`, `.lower()`, `.replace(" ", "")`.

**Файл:** `palindrom.py`

**Проверка у себя:** `python check.py 4.2`
