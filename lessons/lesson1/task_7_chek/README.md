# Задание 1.7. Чек из магазина

Спроси название товара, цену (целое) и количество (целое). Выведи `<товар>: <цена> * <количество> = <итого>`.

**Пример.** Ввод:

```
Тетрадь
30
4
```

Вывод:

```
Тетрадь: 30 * 4 = 120
```

**Подсказка:** Три `input()`. Цену и количество превращай в `int()`. Итог можно посчитать прямо в f-строке: `{price * count}`.

**Файл:** `chek.py`

**Проверка у себя:** `python check.py 1.7`
