# Задание 1.1. Визитка

Спроси у пользователя имя и город. Выведи одну строку: `Меня зовут <имя>, я из <город>`.

**Пример.** Ввод:

```
Анна
Москва
```

Вывод:

```
Меня зовут Анна, я из Москва
```

**Подсказка:** Две переменные через `input()` и `print()` с f-строкой.

**Файл:** `vizitka.py`

**Проверка у себя:** `python check.py 1.1`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
