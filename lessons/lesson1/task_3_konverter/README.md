# Задание 1.3. Километры в метры

Спроси расстояние в километрах (может быть дробным). Выведи `<число> м`.

**Пример.** Ввод:

```
1.5
```

Вывод:

```
1500.0 м
```

**Подсказка:** Дробное число — `float(...)`. В километре 1000 метров.

**Файл:** `konverter.py`

**Проверка у себя:** `python check.py 1.3`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
