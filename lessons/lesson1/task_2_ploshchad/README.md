# Задание 1.2. Площадь прямоугольника

Спроси длину и ширину (целые числа). Выведи `Площадь: <число>`.

**Пример.** Ввод:

```
4
5
```

Вывод:

```
Площадь: 20
```

**Подсказка:** `int(input(...))`, потом умножение.

**Файл:** `ploshchad.py`

**Проверка у себя:** `python check.py 1.2`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
