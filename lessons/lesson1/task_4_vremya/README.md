# Задание 1.4. Минуты в часы

Спроси количество минут (целое). Выведи, сколько это часов и минут: `<ч> ч <м> мин`.

**Пример.** Ввод:

```
135
```

Вывод:

```
2 ч 15 мин
```

**Подсказка:** Целочисленное деление `//` и остаток `%`.

**Файл:** `vremya.py`

**Проверка у себя:** `python check.py 1.4`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
