# Задание 1.6. Среднее трёх оценок

Спроси три оценки (целые, каждая отдельно). Выведи `Среднее: <число>`. Деление `/` всегда даёт дробное число: `4.0`, а не `4`.

**Пример.** Ввод:

```
5
4
3
```

Вывод:

```
Среднее: 4.0
```

**Подсказка:** Сложи три числа в скобках и раздели на 3: `(a + b + c) / 3`.

**Файл:** `srednee.py`

**Проверка у себя:** `python check.py 1.6`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
