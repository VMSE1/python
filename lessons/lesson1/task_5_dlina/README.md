# Задание 1.5. Длина имени

Спроси имя. Выведи `<имя>: букв <число>`.

**Пример.** Ввод:

```
Анна
```

Вывод:

```
Анна: букв 4
```

**Подсказка:** `len(...)` считает символы в строке. Собери ответ через f-строку.

**Файл:** `dlina.py`

**Проверка у себя:** `python check.py 1.5`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
