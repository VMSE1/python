# Задание 3.8. Три попытки

Пароль: `python`. Дай пользователю **3 попытки** ввести его. Угадал: выведи `Доступ открыт` и сразу закончи. Ошибся: выведи `Неверно`. Если все 3 попытки неверные, в конце выведи `Доступ закрыт`.

**Пример:**

Ввод:
```
qwerty
python
```
Вывод:
```
Неверно
Доступ открыт
```

**Подсказка:** `for i in range(3):`, внутри `if ... : break`. После цикла пригодится флажок `ok = False`.

**Файл:** `parol.py`

**Проверка у себя:** `python check.py 3.8`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
