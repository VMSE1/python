# Задание 3.5. Наибольшее в списке

Напиши функцию `biggest(numbers)`: вернуть наибольшее число списка. **Без** встроенной `max()` — циклом.

**Пример вызова:**

```python
>>> biggest([3, 9, 2])
9
```

**Подсказка:** Возьми первый элемент как «рекордсмена» и сравнивай с остальными.
