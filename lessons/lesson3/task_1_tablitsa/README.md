# Задание 3.1. Таблица умножения

Спроси число `n`. Выведи 10 строк вида `n x i = результат`, где `i` от 1 до 10.

**Пример.** Ввод:

```
7
```

Вывод:

```
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

**Подсказка:** `for i in range(1, 11):`

**Проверка у себя:** `python check.py 3.1`
