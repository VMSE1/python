# Задание 3.4. Функция recommend

Напиши функцию `recommend(distance)`. До 2 км включительно возвращает `пешком`, до 8 включительно — `на наземном транспорте`, иначе `на метро`. Функция **возвращает** строку, а не печатает.

**Пример вызова:**

```python
>>> recommend(12)
на метро
```

**Подсказка:** Те же условия, что в задании 2.4, но с `return`.
