# Задание 3.6. Чётные до n

Спроси число `n`. Выведи все чётные числа от 2 до `n`, каждое с новой строки. В конце выведи `Всего: <сколько их было>`.

**Пример:**

Ввод:
```
7
```
Вывод:
```
2
4
6
Всего: 3
```

**Подсказка:** `range(2, n + 1, 2)` и счётчик `count += 1`.

**Файл:** `chetnye.py`

**Проверка у себя:** `python check.py 3.6`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
