# Задание 3.7. Сумма цифр

Напиши функцию `digit_sum(n)`: она **возвращает** сумму цифр числа `n` (n ≥ 0). Сделай циклом `while`, без перевода в строку.

**Пример вызова:**

```python
>>> digit_sum(1234)
10
```

**Подсказка:** Последняя цифра: `n % 10`. Убрать её: `n //= 10`. Повторяй, пока `n > 0`.
