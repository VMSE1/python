# Задание 3.3. Чек в магазине

Пользователь вводит цены по одной, пока не введёт `стоп`. В конце выведи `Итого: <сумма>`.

**Пример.** Ввод:

```
100
50.5
стоп
```

Вывод:

```
Итого: 150.5
```

**Подсказка:** `while True`, `break` по слову `стоп`, накопитель.

**Файл:** `pokupki.py`

**Проверка у себя:** `python check.py 3.3`

**Сдача:** на сайте курса (страница задания → «Отправить на проверку») или Issue «Сдать задание».
