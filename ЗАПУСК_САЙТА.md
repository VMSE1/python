# Как запустить сайт курса (один раз, ~5 минут)

Репозиторий: https://github.com/VMSE1/python — всё уже загружено. Осталось включить сайт.

## Шаг 1. Включить сайт (GitHub Pages)

1. Открой https://github.com/VMSE1/python и войди в свой аккаунт.
2. Вверху нажми **Settings** (шестерёнка). Если вкладки нет — ты не вошёл в аккаунт владельца.
3. Слева в меню найди **Pages**.
4. В блоке **Build and deployment** → поле **Source** → выбери **GitHub Actions**. Сохранять ничего не нужно.

## Шаг 2. Запустить сборку

1. Вверху репозитория нажми **Actions**.
2. Слева выбери **Сайт**.
3. Справа нажми **Run workflow** → зелёная кнопка **Run workflow**.
4. Подожди 1–2 минуты. Рядом с запуском появится зелёная галочка ✅.

Если красный крестик ❌: нажми на запуск и пришли мне скриншот.

## Шаг 3. Открыть сайт

Адрес: **https://vmse1.github.io/python/**
(также ссылка есть в Settings → Pages после успешной сборки.)

## Шаг 4. Проверить, что сдача работает

1. Открой сайт → любое задание, например **2.4**.
2. Вставь в окно кода решение (из архива `Решения_заданий_GitHub_для_учителя.zip`, файл `2.4_gorodskoy_pomoshchnik.py`).
3. Впиши ник `test` → **Отправить на проверку**.
4. Откроется GitHub. Нажми зелёную кнопку **Submit new issue**.
5. Через минуту в этом Issue появится комментарий робота: ✅ **Решено!**
6. Зайди в кабинет учителя (см. `ИНСТРУКЦИЯ_УЧИТЕЛЮ.md`, раздел «Кабинет»): в сводке должна появиться строка `test`.

Не отвечает робот → вкладка Actions → «Проверка сдачи» → открой запуск и пришли мне скриншот.

## Шаг 5. Дать ссылку ученикам

Пришли им адрес сайта. Для сдачи нужен бесплатный аккаунт GitHub (регистрация на github.com — почта и пароль).
Скажи ребятам: в поле «Ник» писать **псевдоним, не настоящую фамилию** (заявки видны всем). Таблицу «ник — ученик» держи у себя.

## Что ещё полезно

- **Тест:** страница «Тест» на сайте. Ученик в конце присылает тебе длинный код. Вставляешь коды на странице «Для учителя» (ссылка внизу сайта) → таблица результатов.
- **Кабинет:** `teacher.html`, вход токеном GitHub (только владелец).
- **Добавить задание:** см. `CONTRIBUTING.md`. После изменений сайт обновляется сам.
- **Если GitHub не открывается в школе:** ученики скачивают ZIP репозитория (Code → Download ZIP), решают в VS Code и проверяют командой `python check.py 2.4`.
