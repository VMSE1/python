# Проекты учеников

Самый простой способ показать проект — Issue «Показать свой проект» (он появится на сайте).

Хочешь добавить проект в репозиторий:

1. Fork этого репозитория.
2. Создай папку `projects/твой_ник/`, положи туда `main.py` и `README.md` (что делает программа, как запустить).
3. Pull Request в `main`.

Правила: только свой код, без паролей и личных данных, без чужих ников и фамилий.
