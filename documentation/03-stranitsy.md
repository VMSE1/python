# 3. Страницы сайта

Все страницы открываются как окна Windows 95 с кнопками «Назад» и «Закрыть», меню «Пуск» и часами на панели задач. Общий код оболочки в `docs/site.js` (функция `layout()`).

| Страница | Файл | Что делает | Откуда берёт данные |
|---|---|---|---|
| Рабочий стол | `index.html` | Иконки разделов, кнопка «Начать/Продолжить» с твоим следующим заданием, подсказка «Нажми сюда!» при первом входе | `data/tasks.js`, `localStorage` |
| Задания | `tasks.html` | Карта курса: уроки, задания, отметки «сдано» | `data/tasks.js`, `localStorage` |
| Задание | `task.html?id=2.4` | Условие, подсказка, редактор, «Проверить здесь», «Отправить учителю», поля «Ник» и «Группа» | `data/tasks.js`, Pyodide |
| Теория | `theory.html` | 29 шпаргалок по урокам, с примерами кода | `data/theory.js` |
| Квизы | `quiz.html` | Список квизов (по урокам и весь курс), вопросы, результат и код для учителя | `questions.js` |
| Проекты | `projects.html` | Работы ребят с 👍 и комментариями | Issues с меткой `проект` |

| Кабинет учителя | `teacher.html` | Сводка, ученики, результаты квизов, выгрузки | Issues с меткой `сдача` |
| Как это работает | окно из «Пуска» (`guide.js`) | Пять слайдов с анимированным курсором | встроено |

## Что хранится в браузере ученика (`localStorage`)

| Ключ | Что |
|---|---|
| `nick`, `group` | Ник и группа, чтобы не вводить каждый раз |
| `done`, `passed` | Какие задания отправлены и какие прошли проверку в браузере |
| `visited`, `seenStart` | Видел ли ученик подсказки и инструкцию |
| `qname` | Имя в квизе |
| `<id задания>` | Черновик кода (сохраняется при вводе) |

Всё это только в браузере ученика. Если очистить данные сайта, отметки пропадут (на GitHub сдачи остаются).

## Рабочий стол и меню

В «Пуске»: Задания, Теория, Квизы, Проекты ребят, Облако слов, Презентации, Вход для учителя, «Как это работает», Рабочий стол, Исходники (GitHub).

## Задание (`task.html`)

1. Условие и пример берутся из `task.json`.
2. «Проверить здесь» запускает код в Pyodide (Web Worker, лимит 8 секунд, после лимита воркер перезапускается). Pyodide грузится лениво: только когда ученик начал писать или нажал проверку.
3. «Отправить учителю» собирает адрес `issues/new?template=submit.yml&title=…&nick=…&group=…&task=…&code=…` и открывает GitHub в новой вкладке.
4. Вставка в редактор отключена (см. [04](04-proverka-i-bezopasnost.md)). Ник и группа обязательны. Подсказка на странице просит не писать фамилию.

## Квизы

41 вопрос, 4 варианта, у каждого есть объяснение «почему». В конце ученик получает длинный код результата и присылает его учителю; учитель вставляет коды в кабинет (вкладка «Тест»).

## Теория

Плашки с коротким текстом и кодом. Некоторые привязаны к заданиям (`THEORY_MAP`), поэтому подсказка в задании ведёт на нужную плашку.

## Проекты

Ученик создаёт Issue «Показать свой проект». Робот ставит метку `проект`, страница показывает карточку: автор, описание, 👍, число комментариев и ссылку. Проект можно добавить и Pull Request'ом в `projects/ник/`.
