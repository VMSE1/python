# 11. Видеоразборы

Короткие ролики (30–60 секунд) прямо на сайте. Это не видеофайлы, а анимация на настоящих стилях сайта: весит несколько килобайт, работает без интернета и без GitHub.

## Где они есть

| Место | Что показывает |
|---|---|
| Главный экран, кнопка «Видеогид» | Как сдать задание от начала до конца, с GitHub и без |
| Страница «Видеоразборы» (`video.html`) | Все ролики по уровням |
| Теория, вкладка урока | «Видеоразбор» над шпаргалкой |
| Задание, правая колонка | «Смотреть задание» (1.2, 2.2, 3.4) и ролики по теме урока |

## Два вида роликов

1. **Задание** (`type: "task"`). Копия настоящей страницы задания: условие, пример, подсказка, редактор, проверка, отправка. Курсор кликает, код печатается, `Ctrl+V` блокируется, робот отвечает. Решение, которое печатается, проверяется автотестом настоящей проверкой.
2. **Теория** (`type: "trace"`). Код, «память» с переменными и их типами, окно вывода. Это настоящий запуск через `sys.settrace`, а не рисунок: значения в памяти и вывод берутся из реального выполнения.

## Как добавить ролик

Всё лежит в `tools/make_clips.py`.

- Теория: добавь словарь в `THEORY_CLIPS`: `code`, `inputs`, `intro`, `outro` и `caps`. В `caps` ключ это номер строки с нуля, значение: подписи по заходам на строку (для цикла по одной на круг). `{имя}` подставляет значение переменной. Если подписи для строки нет, скрипт остановится и скажет какой.
- Задание: добавь словарь в `TASK_CLIPS`: `task` (номер), `keep` (что остаётся от заготовки), `typed` (что печатается), `caps.type` (пояснение к решению).
- Запусти `python3 tools/make_clips.py` и закоммить `docs/data/clips.js`.

Показано состояние после выполнения строки: подпись «теперь total равно 3» всегда совпадает с памятью справа.

## Файлы

| Файл | Роль |
|---|---|
| `docs/explainer.js` | Плеер: пауза, перемотка, скорость, главы, окно поверх страницы |
| `docs/explainer.css` | Стили плеера и карточек |
| `docs/data/clips.js` | Данные (генерируется) |
| `docs/video.html` | Страница со всеми роликами |
| `tools/make_clips.py` | Генератор данных |

Тесты: набор `video` в `tests/browser_tests.py` (решения проходят проверку, все ролики проигрываются, кнопки открывают плеер, телефон без горизонтальной прокрутки).
