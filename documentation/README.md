# Документация Python-курса

Бесплатный курс по Python для школьников на GitHub: сайт в стиле Windows 95, автопроверка кода, квизы, проекты, облако слов, презентации с запуском кода и кабинет учителя.

**Сайт:** https://vmse1.github.io/python/ · **Робот-ведомость:** репозиторий `VMSE1/BotBD` (приватный)

## С чего начать

| Ты кто | Читай |
|---|---|
| Ученик | [01. Обзор](01-obzor.md), раздел «Как учиться» |
| Учитель, первый запуск | [`ЗАПУСК_САЙТА.md`](../ЗАПУСК_САЙТА.md), затем [05. Кабинет и BotBD](05-kabinet-i-botbd.md) |
| Хочу добавить задание, вопрос, слайд | [09. Разработка](09-razrabotka.md) |
| Хочу понять, как всё устроено | [02. Архитектура](02-arhitektura.md) |
| Беспокоит безопасность и данные детей | [04. Проверка и безопасность](04-proverka-i-bezopasnost.md) |

## Оглавление

1. [Обзор](01-obzor.md): что это, для кого, цифры, как учиться

3. [Страницы сайта](03-stranitsy.md): что делает каждая страница и откуда берёт данные
4. [Проверка кода и безопасность](04-proverka-i-bezopasnost.md): песочница, браузерная проверка, CSP, персональные данные
5. [Кабинет учителя и робот BotBD](05-kabinet-i-botbd.md): ведомость, группы, ФИО
6. [Облако слов](06-oblako-slov.md): хранилище в Issues, правила подсчёта, модерация
7. [Презентации](07-prezentacii.md): движок слайдов, запуск кода, как сделать свою
8. [Тесты](08-testy.md): что и чем проверяется, как запускать
9. [Разработка](09-razrabotka.md): добавить задание, теорию, вопрос, слайд; дизайн-токены; выпуск
10. [История и план](10-istoriya-i-plan.md): что сделано по этапам, известные ограничения, что дальше
