# Передача проекта в новый диалог

Коротко, чтобы начать новый диалог без потери контекста.

## Что это
Сайт `https://vmse1.github.io/python/` (папка `docs/`, GitHub Pages, стиль Windows 95) и сервер на VPS `https://course.2-27-53-182.sslip.io` (папка `server/`, aiohttp + SQLite). Курс Python для 9 класса, преподаватель Александр.

## Состояние на 22.10.2026
- Ученики регистрируются в первом окне (логин, пароль, почта), GitHub не нужен. Сдача заданий идёт на сервер и проверяется там.
- Кабинет учителя: вход по ключу сервера (`/etc/pycourse.env`), вкладки «Игра», «Сдачи», «Пароли», «Ученики», «Тест».
- Гонка по Python для всех, рулетка «три черепа» с игрой «Скелет и бочки», секреты, экраны объявлений через `docs/notice.json`.
- Защита: честный ввод `honest.js` (вставка, F12, боты), блокировка входа по нарастающей, лимиты почты, песочница `check.py`.

## Тесты
    python3 -m unittest tests.test_sandbox tests.test_server
    python3 tests/browser_tests.py            # все наборы; один набор: ... race | gate | lucky | online | ...
Нужны `pip install aiohttp playwright` и Chromium.

## Что делает владелец вручную
1. Подключить репозиторий к сессии с правом записи, если нужно пушить из чата.
2. Обновить сервер: `curl -fsSL https://raw.githubusercontent.com/VMSE1/python/main/server/install.sh | bash`.
3. Для писем: добавить SMTP-переменные в `/etc/pycourse.env` (см. `13-server.md`), перезапустить `pycourse`.
4. Сменить пароль root VPS (он был написан в чате).
5. Приватный репозиторий BotBD и запуск робота, если нужна выгрузка.

## Правила работы с владельцем
Отвечать прямо и коротко, без воды, критика вместо вежливого согласия, ничего платного, не хвалить без дела, конкретные задачи и сроки.
