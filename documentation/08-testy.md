## Как запускать

```bash
python3 -m unittest tests.test_sandbox -v          # атаки на песочницу
pip install playwright && playwright install chromium
python3 tests/browser_tests.py                     # весь браузерный набор
python3 tests/browser_tests.py smoke functional    # только выбранные части
python3 tests/browser_tests.py slides              # только презентация
```

Части: `smoke`, `functional`, `teacher`, `slides`, `perf`, `stress`. На GitHub в каждом push идут песочница, `smoke`, `functional`, `teacher` и `slides`; `perf` и `stress` запускай локально.

## Что проверяется

| Часть | Идея | Примеры |
|---|---|---|
| **smoke** | Страницы живые | Все страницы открываются на 1280 и 390 пикселей без ошибок, без горизонтального скролла, со шрифтами; нет 404; все внутренние ссылки открываются |
| **functional** | Пользовательские сценарии | Рабочий стол, «Пуск», инструкция, задания, проверка в браузере, отправка (ник, группа, ссылка на заявку), квизы, проекты, облако слов (темы, голоса, скрытые заявки, ссылка на форму, пустое состояние) |
| **teacher / security** | Кабинет и защита | Вход только владельца, токен 7 дней, выгрузка Excel, `students.csv`, формулы в CSV, XSS в никах и словах, CSP, clickjacking |
| **slides** | Презентация | Клавиши, пункты по одному, оглавление, калькулятор, запуск кода по шагам, ползунок, игра про границы, консоль, XSS в имени, 23 слайда без горизонтального скролла на телефоне и без обрезки на ноутбуке 1366×768 |

## Как работают браузерные тесты

- Playwright запускает Chromium, поднимает локальный сервер на `docs/`.
- Запросы к `api.github.com` подменяются заглушкой (`mock_github`): тесты не ходят в настоящий GitHub и не зависят от лимитов.
- Для каждой проверки печатается `PASS` или `FAIL` и подробность; в конце «ИТОГО».

## Как добавить тест

1. Открой `tests/browser_tests.py`, найди нужную часть (функция `smoke`, `functional`, `teacher`, `slides`).
2. Вызови `check("описание", условие, подробности)`.
3. Для данных Issues используй помощники `issue()` (сдача) или локальный `ci()` (облако слов).
4. Для новой страницы добавь её в список `PAGES` вверху файла: smoke проверит её автоматически.
