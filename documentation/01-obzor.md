# 1. Обзор

## Что это

Сайт и набор заданий, на которых школьник учит Python за пять уроков. Всё бесплатно: сайт живёт на GitHub Pages, проверка идёт либо в браузере ученика, либо на бесплатных серверах GitHub Actions.

## Для кого

- **Ученики 12–17 лет.** Нужен бесплатный аккаунт GitHub и браузер. Устанавливать Python не обязательно.
- **Учитель.** Видит сводку по группам, выгружает ведомость в Excel, добавляет задания и вопросы без серверов.

## Уроки

1. **Первая программа**: `print`, переменные, арифметика (визитка, площадь, километры в метры, минуты в часы).
2. **Условия**: светофор, оценка, аттракцион, «Городской помощник 1.0».
3. **Циклы, списки, функции**: таблица умножения, сумма, чек, функция `recommend`, наибольшее.
4. **Строки, словари, файлы**: слова, палиндром, частота букв, переводчик, запись в файл.
5. **Ошибки и проект**: безопасный `int`, деление, повторный ввод, «Городской помощник 3.0».

Список с номерами ведёт [`README.md`](../README.md) (таблица собирается автоматически).

## Как учиться (путь ученика)

1. Открыть сайт, нажать «Начать» на рабочем столе.
2. Выбрать задание на карте, написать код в окне и нажать «Проверить здесь»: ответ приходит сразу, без интернета после загрузки страницы.
3. Нажать «Отправить учителю»: открывается GitHub с готовой заявкой (ник, группа, задание, код). Нажать **Submit new issue**.
4. Через минуту робот отвечает комментарием: ✅ решено или что не так. Исправил заявку: проверка запустится заново.
5. Дополнительно: квизы, теория-шпаргалки, проекты ребят, облако слов, презентации.

Настоящую фамилию в заявке писать нельзя: Issues видны всем. Вместо неё ник и номер группы.

## Принципы

- **Бесплатно**: никаких платных сервисов, ключей и серверов.
- **Работает в школьной сети**: все шрифты и Pyodide лежат в репозитории, внешних CDN нет.
- **Данные детей не публикуются**: в открытых заявках только ник и группа; ФИО только у учителя.
- **Без сборки**: чистый HTML, CSS, JS и Python. Любой может открыть файл и поправить.
