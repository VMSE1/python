|---|---|
| 1. Основа | Репозиторий с заданиями, `check.py`, форма сдачи в Issues, автопроверка роботом, сайт на Pages, тест, проекты |
| 2. Первый дизайн | Плашки теории, окно-инструкция, светлая и тёмная тема |
| 3. Карта курса | Карта заданий, проверка кода в браузере (Pyodide), анимированный мастер «Как это работает», кабинет учителя |

| 8. Облако слов | Функция `WordCloud.render`, затем хранилище в Issues, темы, подсчёт голосов, модерация меткой `скрыто` |
| 9. Документация и презентации | Эта документация; презентация «Городской помощник» в стиле сайта с запуском кода по шагам |

## Известные ограничения

- Публичный репозиторий: сдачи видны всем (поэтому ник и группа, без ФИО).
- Облако и списки обновляются по кнопке; у GitHub API без токена лимит 60 запросов в час на IP.
- Проверка ответов видна в браузере, ученик может подогнать вывод.
- Кабинет учителя защищён на уровне интерфейса, данные сдач публичны; закрытая часть это BotBD.
- Презентация одна. Игра на pygame и `demo.html` из исходного набора в репозиторий не входят.
- Живой сайт (`vmse1.github.io`) недоступен из среды разработки, поэтому всё проверялось локально и в Actions.
