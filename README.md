# Python-курс

Бесплатный курс по Python для школьников: короткие задания, автопроверка за минуту, тест и свои проекты.

**Сайт курса:** `https://VMSE1.github.io/python/` (включается в Settings → Pages → Source: GitHub Actions)

📚 **Полная документация:** [`documentation/`](documentation/README.md) (архитектура, страницы, безопасность, облако слов, презентации, тесты).

## Как учиться

1. Открой сайт курса → выбери задание на карте.
2. Напиши код прямо в окне на странице и нажми **«Проверить здесь»**: ответ сразу.
3. Нажми **«Отправить учителю»**: откроется GitHub с готовой заявкой. Нажми *Submit new issue*.
4. Через минуту робот ответит комментарием: ✅ решено или что не так. Исправил — нажми *Edit* у заявки, проверка запустится снова.

Нужен бесплатный аккаунт GitHub. **Нет аккаунта?** Под редактором открой «Нет GitHub? Отправь без него», впиши фамилию и имя, нажми «Получить код сдачи» и отправь этот код учителю (мессенджер, почта, файл). **Настоящую фамилию не пиши — всё видно всем. Придумай ник.**

### Без аккаунта

Скачай репозиторий (Code → Download ZIP), открой папку в VS Code, решай задание в файле `.py`, проверяй:

```
python check.py 2.4
```

### Свои проекты

Сделал свою программу? Issues → New issue → **«Показать свой проект»**. Проект появится на странице «Проекты», другие смогут поставить 👍 и прокомментировать. Хочешь добавить проект прямо в репозиторий — Fork → папка `projects/твой_ник/` → Pull Request (см. `projects/README.md`).
